# Press-On Nail Book

A virtual flip-book that displays my press-on nail sets, built as a static website.

## Project goal
Give customers a simple, good-looking way to browse my press-on nail designs online, instead of scrolling through scattered photos.

## MVP scope
- `nails.json` data file with sample nail sets and photos
- Each set rendered as a page, built from the JSON
- Page-flip book with a cover and back cover (StPageFlip)

## Future plans (V2.0+)
- Filters by shape, length, and color
- Order/inquiry button linking to Instagram or a form
- AR virtual try-on

## Tech stack
- **Languages:** HTML, CSS, JavaScript
- **Libraries:** StPageFlip (book effect), PhotoSwipe (photo zoom), Tailwind CSS
- **Storage:** `nails.json` plus an `images/` folder of WebP photos
- **Hosting:** GitHub Pages
